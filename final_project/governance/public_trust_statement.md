# Public Trust Statement

This project is an academic customer-churn analytics prototype built from a public dataset. It identifies statistical patterns associated with the dataset's churn label. It does not determine why a customer left, does not predict a verified future churn date, and has not been validated on Netflix production data.

The system is designed for transparent decision support. Customer identifiers are not used as predictors, age and gender are excluded from model training and are used only for fairness auditing, and model outputs are accompanied by explainability, fairness and monitoring evidence. Any real operational use would require current production data, privacy and security review, legal review, user-impact assessment, and ongoing human oversight.
